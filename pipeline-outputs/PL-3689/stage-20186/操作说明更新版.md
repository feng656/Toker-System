## 〇、开始之前

### 怎么打开系统

1. 后端与前端在同一进程里（FastAPI 挂载 `web/` 目录）：

   ```bash
   pip install -r requirements.txt
   # .env 按 .env.example 填写（至少 DATABASE_URL、MINIO_*、JWT_SECRET、DEEPSEEK_KEY）
   uvicorn app.main:app --host 0.0.0.0 --port 8300
   ```

2. 浏览器打开 `http://<服务器地址>:8300`，用账号登录。
3. ⚠️ **不要直接双击 `web/index.html`**：前端使用 ES 模块，必须通过上面的服务地址访问，否则浏览器会因模块跨域而白屏。

## 一、每天 3 步（运营）

### 第 1 步：看今天要发什么

登录后左侧菜单：

| 菜单 | 什么时候看 |
| --- | --- |
| ⚡ **工作台** | 今天的投放主战场：左侧内容池，右侧四个平台通道，**拖一下就能把内容投到对应平台**；右侧还可扫码登录各平台后台 |
| 📋 **今日待办** | 左边带红色数字的就是今天要发的；**按日期切换**可以补看前几天的漏发 |
| 📝 **内容管理** | 要改文案、看驳回理由、查某个版本为什么被拦 |

「今日待办」页面顶部可以直接点 **「生成明日内容包」**（每天 08:00 也会自动生成一次），生成在后台跑，**约 2–4 分钟**后再回来看。

### 第 2 步：工作台拖动投放 → 去平台发布

**工作台现在分成两栏：左边是内容池，右边是平台通道（抖音 / 小红书 / 公众号 / 闲鱼 四个 tab）。**

操作顺序：

1. 在左侧找到今天要发的内容卡（平台徽标、业务线、标题、质量分、合规状态、正文、话题、素材状态）；
2. **把卡片拖到右侧的平台 tab 上松手**——系统会做两件事：把该平台的格式文案（标题 / 正文 / 话题 / 行动引导 / 免责声明）**复制到剪贴板**，并**自动填好右栏 composer**；
3. 在 composer 里微调（各平台字段不同）：

   | 平台 | composer 字段 | 到哪发 |
   | --- | --- | --- |
   | 抖音 | 标题、口播文案、话题、封面、视频或图文 | 抖音 APP → 发布 → 图文/视频（口播脚本 60 秒，开头 3 秒抛痛点） |
   | 小红书 | 标题、正文、话题、图片 | 小红书 APP → 发布 → 笔记（图片至少 1 张） |
   | 公众号 | 标题、正文、封面、摘要 | mp.weixin.qq.com → 草稿箱 → 新建图文（800–1500 字长图文） |
   | 闲鱼 | 标题、描述、价格、成色、图片 | 闲鱼网页版 goofish.com → 发布（**价格只填在后台，不写进文案**） |

4. 点 **「复制文案」** 再次复制最新版本，点 **「打开 XX 后台」** 跳到对应平台，粘贴发布；
5. 发布完成后回到工作台，点 **「标记已发」**，粘贴发布链接回填。

要点：

- **拖动只复制，不发布。** 拖完还要自己点发布按钮，避免误发。
- **跨平台会先问一句。** 把「公众号」版本拖到「抖音」会提示「会按抖音格式重排，是否继续？」，确认后按目标平台重排字段。
- **手机/窄屏没有拖拽**：每张卡片上有 **「复制到…」** 下拉，选平台即可，效果与拖动一致。
- **免责声明已自动附在文案末尾**（4.1 公众号/长图文版，四平台统一），不用自己补。
- **行动引导按平台区分**：抖音私信、小红书评论或私信、公众号留言或加微信、闲鱼站内信。
- **素材不够也能干**：内容池顶部有「素材库覆盖」统计（可公开 / 需脱敏 / 仅内部）。素材库为空时会显示空状态并给两个入口——**「去素材库补充」**和**「先用文字版」**（媒体字段留空，其余照常投放），不阻塞工作。

在「今日待办」里点 **「复制文案」** 仍然是可用的备用路径（复制整条正文 + 话题）：

| 平台 | 在哪发 | 发什么 |
| --- | --- | --- |
| 公众号 | mp.weixin.qq.com → 草稿箱 → 新建图文 | 复制「公众号」那条的正文 + 标题（800–1500 字长图文） |
| 抖音 | 抖音 APP → 发布 → 图文/视频 | 复制「抖音」那条口播脚本（60 秒，开头 3 秒抛痛点） |
| 视频号 | 视频号助手 channels.weixin.qq.com | 同抖音脚本，偏行业分享口吻 |
| 朋友圈 | 微信直接发 | 复制「朋友圈」短文案，销售人手一条 |

> **一期以人工发布为准。** 平台官方接口（自动发布）目前是「可插拔增强」：只有管理员在「设置」里配好凭据、且平台完成企业认证后，个别平台才会显示为「可自动发布」。**公众号必须先做企业认证（¥300/年，腾讯收）并把服务器 IP 加进白名单**，这一步绕不开，与系统无关。
> 工作台上的 **「发布（API）· P1 接入」** 按钮当前是置灰的：真实平台发布 API 属 P1 阶段（抖音 → 公众号 → 小红书 → 闲鱼按序接入），一期走「复制 + 人工发布」。

### 第 3 步：回填发布链接（必做）

回到「今日待办」，在对应条目里粘贴链接，点 **「确认回填」**；在**工作台**上则是点 composer 里的 **「标记已发」**，在弹框里粘贴链接。

- 链接必须以 `http://` 或 `https://` 开头；留空或格式不对会被拦下并提示。
- **不填链接 = 没发布**：该版本不会计入「数据看板」的已发布数量，也不会再出现在待办里。这是硬门槛，不允许绕过。工作台的「标记已发」同样必须填链接，不会出现「标了但没链接」的假已发布。
- 回填成功的条目会显示「已发布 + 可点链接」，并计入看板。

### 第 4 步（可选，但建议）：传截图 + 录数据

待办条目上的 **「上传截图」**：

- 「数据截图（曝光/点赞）」→ 上传后**系统目前不会自动识别**（截图 OCR 还没接），请到「数据看板 → 录入效果数据」手工填版本 ID 与数值；
- 「评论截图」→ 目前同样不会自动识别，请把评论原文粘贴到「线索看板 → + 录入评论 / 私信」。

> 指标录入口径：**同一个版本 + 同一天重复录入会覆盖更新，不会重复累加**。

## 二、线索跟进（销售）

1. 打开「🎯 线索看板」，筛选「意向 = 高意向」（默认建议只看高意向）。
2. 点「指派销售」填自己的名字（管理员账号下是下拉选择）；状态改成「已联系」。
3. 每通一次电话/微信，点 **「联系记录」** 写一条（例：已电话沟通，对方要 3 米 P2.0，报价走私信，约定周三发方案）。
4. 推进状态：新线索 → 已联系 → 已加微 → 商机 → 已成交 / 已流失。
5. 「推送企微」会往企微群发高意向提醒；**没收到不代表失败，先看页面提示**，未配置企微机器人时它会明确告诉你失败原因，再点一次可重试。

注意事项：

- **没有跟进记录的高意向线索不要直接标「商机」**。
- **发现重复联系方式不要新建**：系统暂未实现自动去重（后端能力缺口 GAP-08），看板「数据质量提示」会列出重复联系方式，请人工合并（保留最早一条，跟进记录并到同一条）。
- 销售账号看不到素材和内容页面，这是权限设计，不是故障。

## 三、看数与验收（负责人 / 产品）

「📊 数据看板」：

- 顶部五个数：已发布内容 / 总曝光 / 评论私信 / 线索总数 / 高意向；
- 第二条是 **「数字 vs 明细」一致性核对**：绿条表示看板数字与明细条数一致，红条表示不一致（多半是有人发了没回填链接）；
- 「异常状态」列出：命中红线、发布失败、待人工确认、未回填链接、未指派线索、**高意向未指派**（优先处理）、无联系方式；
- 「线索质量提示」列出重复联系方式；
- 「近 7 天发布趋势」是前端按明细里的发布时间本地聚合的（后端暂无趋势接口），仅供趋势参考。

验收时按《九步验收脚本与结果.md》逐条走，每步都有「输入 / 预期结果 / 实际结果」，可直接对照操作。

## 五、常见问题

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 打开是白屏 | 直接双击了 `web/index.html` | 必须通过 `uvicorn app.main:app` 的地址访问 |
| 工作台拖不动 / 拖过去没反应 | 手机或窄屏没有拖拽能力；或拖的不是内容卡本身 | 窄屏用卡片上的「复制到…」下拉；桌面端拖内容卡（不是拖按钮） |
| 拖到别的平台弹了「是否继续」 | 内容版本平台与目标通道不一致，属正常防错投提示 | 确认后按目标平台重排字段；不想投就点取消 |
| 复制出来的文案里没有图片/视频 | 素材库还没补图，或当前是「纯文字版」 | 图片需在平台后台上传；工作台只负责文案与结构 |
| 闲鱼价格没出现在文案里 | 价格口径：文案不出现价格数字 | 在闲鱼后台的价格栏单独填写 |
| 「发布（API）」按钮点不动 | 真实平台 API 属 P1 阶段 | 一期用「复制文案 + 打开后台」人工发布 |
| 点「标记已发」报错 | 没填链接或链接不是 http(s) 开头 | 按提示粘贴完整发布链接再提交 |
| 登录提示「账号或密码错误」 | 输错 / 账号未创建 | 找管理员在「设置 · 用户管理」建账号 |
| 点「生成明日内容包」没反应 | 生成在后台跑，约 2–4 分钟；或大模型 Key 未配置 | 等几分钟回「内容管理」看；仍无内容找后端查 AI 调用日志 |
| 待确认里是空的 | 本批内容质检分 < 70 或命中红线 | 到「内容管理」展开版本看质检评语与命中词，改写后保存（保存会自动重跑合规检查） |
| 某条内容不在待办里 | ① 被驳回 ② 已回填链接 ③ 内容状态不是草稿/已通过 | 「内容管理」按状态筛选查看 |
| 点「确认发布」提示失败 | 平台没配凭据 / 没登录 / 公众号没认证 | 系统会自动复制文案并打开后台，改人工发布即可 |
| 回填链接点不动 | 链接为空或不是 http(s) 开头 | 粘贴完整链接（含 https://） |
| 截图上传了但数据没进看板 | OCR 未接入 | 到「数据看板」手工录入指标 |
| 企微收不到高意向提醒 | 未配置 `WECOM_WEBHOOK` 或网络失败 | 在线索页手动再点一次「推送企微」；仍失败找后端 |
| 看板数字和明细对不上 | 有内容发布后没回填链接 | 数据看板红条会指出差异；回「今日待办」补回填 |
| 选日期后待办是空的 | 该日期确实没有待发布内容 | 换日期或生成内容包 |

## 七、一期**不**包含（别当故障）

平台全自动发布（凭据到位可试但不作为验收前提；工作台「发布（API）· P1 接入」按钮为置灰）、截图 OCR 自动识别、竞品爬取、达人管理、多组织多品牌、线索自动去重、素材批量导入接口、选题表现分自动回填。

> P0 工作台只做「内容 → 文案 → 人工发布」这一段：拖动复制、平台 composer、空素材兜底都已具备；**真实平台发布 API 按 抖音 → 公众号 → 小红书 → 闲鱼 的顺序在 P1 接入**。图片/视频素材需要人工在平台后台上传（工作台的媒体字段只提示素材状态与配图建议）。

> 视频生成属实验能力：后端有相关模块，但当前前端没有入口，需要时单独提需求，不要在日常流程里等它。

以上能力的当前状态与补齐计划见《接口缺口清单.md》。
