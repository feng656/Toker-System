### 步骤 1　导入 3 条素材，建立甲方线和渠道线选题

| 项 | 内容 |
| --- | --- |
| **主责** | 我（产品 / 运营 / 前端与验收） |
| **输入** | 素材：公司简介（通用）、品牌代理（渠道线）、某中学报告厅案例（甲方线，需脱敏）；选题：甲方线 1 条、渠道线 1 条 |

| **预期结果** | 素材和选题可查询、可用于生成 |
| **实际结果** | 接口层：素材 6 条可查（其中新增 3 条）；选题甲方线 2 条、渠道线 2 条可查。页面层：素材库「新增素材」弹窗空标题提交被拦截并提示「素材标题不能为空」，填写后保存成功（卡片 3 → 4）；选题池新增提示「已新增选题」（卡片 2 → 3）；两页筛选（分类 / 业务线 / 公开级别 / 关键词 / 只看启用 / 主题 / 状态）均可用；素材「仅内部」公开级别不会进入生成上下文（口径见《业务规则与状态口径说明》第二节） |
| **结论** | ✅ **通过** |
| **遗留** | 无（批量导入为 P2 缺口，见 GAP-02） |

### 步骤 4　通过 7 个版本

| 项 | 内容 |
| --- | --- |
| **主责** | 我（产品 / 运营 / 前端与验收） |
| **输入** | 内容管理 → 通过 7 个版本 |
| **预期结果** | 今日待办显示 7 条，未通过版本不出现 |
| **实际结果** | 驳回 1 个版本后，**今日待办返回 4 条**（再回填 1 条链接后剩 3 条），而非脚本要求的 7 条。原因：后端驳回粒度是**内容级**，一次驳回把该内容包下 4 个平台版本整体拦下（GAP-03）；待办只取 `status ∈ {draft, approved}` 的内容，因此被驳回整包不再进入待办。已验证「未通过（rejected）版本确实不出现在待办」这一半要求 ✅；红线版本未出现在待办 ✅（本轮演示数据无红线变体）。前端行为正确：待办只渲染 `published_url` 为空的变体，且不显示「已发布」 |
| **结论** | ❌ **不通过**（条数 3 ≠ 7；根因为后端驳回粒度 → GAP-03） |
| **遗留** | ISS-01（同步骤 3）；ISS-02：待办接口补 `date` 参数以便按日期核对（GAP-04） |

### 步骤 5　给 1 条内容回填有效链接

| 项 | 内容 |
| --- | --- |
| **主责** | 我（产品 / 运营 / 前端与验收） |
| **输入** | 今日待办 → 在某条目粘贴 `https://mp.weixin.qq.com/s/demo-acceptance-002` → 点「确认回填」 |
| **预期结果** | 该版本变为已发布，统计增加 1 |
| **实际结果** | ① 回填前 `funnel.published=1` → 回填后 `=2`（**+1**）✅；② 该条目从待办列表消失、卡片显示「已发布」+ 可点链接 ✅；③ **空链接回填被拒绝**：后端返回 400，前端另做非空 + `http(s)://` + 主机名含点校验，页面提示「发布链接不能为空，未回填链接不会计入发布量」/「发布链接需以 http:// 或 https:// 开头」；④ 页面层复验：空链接 → 拦截提示；非法链接 `abc不是链接` → 拦截提示；合法链接 → 成功并计入已发布 |

### 步骤 6　上传数据截图并确认 OCR

| 项 | 内容 |
| --- | --- |
| **主责** | 浆果（后端） |

## 四、复跑方式

```bash

psql "$DATABASE_URL" -c "create database tuoke"        # 首次

# 2) 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8300

# 3) 走九步（真实环境）
#    浏览器登录 http://<host>:8300 → 按本文件「一、逐步记录」的操作列逐步执行
#    每步的「预期结果」即判定标准；实际结果回填到本表并更新版本号
```
