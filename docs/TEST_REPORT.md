## 核心业务断言

- 两条业务线各选四平台，首次生成8版本，同日重复触发不重复生成；每次AI调用有日志，失败任务可重试。
- 驳回必须理由，旧版本和理由保留，自动产生同平台新版本；AI不可用时仍保留驳回并可重试。
- forbidden/ad_law命中及required缺失均blocked，单条和批量审批都不能绕过。
- 通过7个当前版本才出现7条待办；未审/被驳回/历史/未通过质检不出现。
- 空/本机/占位/内部编号链接422，未审核发布409；相同有效形式链接重复回填不增量计数。
- OCR确认前没有metrics/interactions写入；低置信字段缺逐项确认或缺值均422；重传/重复确认幂等。
- 评论进入互动后识别身份、意向、需求、联系方式、回复建议；同联系方式跨平台归并，保留多来源。
- 30天边界、作者兜底、需求相似兜底、不同联系方式防误合并有测试。
- 企微HTTP200业务错误不算成功；CRM503、重试、死信及人工复活均可追踪。
- 销售只见自己线索，不能改派或读全量管理数据；密码修改旧令牌失效。
- 指标upsert与funnel/topics/trend一致，避免聚合倍增。
- 浏览器填稿成功只记filled，不计发布量；官方适配默认关闭，失败记录落库。
