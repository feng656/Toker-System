## 3. 环境变量清单（只列名，不写值）

| 变量 | 用途 | 测试环境 | 生产 |
|---|---|---|---|
| `DATABASE_URL` | 数据库连接 | SQLite 或测试 PG | 必填 |
| `JWT_SECRET` | 登录令牌 | 测试专用 | 必填，≥32 字节 |
| `MINIO_*` / `S3_*` | 对象存储 | 可空（fake） | 必填 |
| `LLM_PROVIDERS` / `LLM_API_KEY` | 文案生成 | 可空（stub） | 必填 |
| `VIDEO_PROVIDER_*` | 视频生成 | 可空 | 按选型 |
| `WECOM_WEBHOOK` | 企微通知 | 可空 | 按需 |
| `CRM_WEBHOOK` | CRM 推送 | 可空 | 按需 |
| `REGISTER_ENABLED` | 自动注册开关 | `false` | 默认 `false` |
| `REGISTER_INVITE_SECRET` | 邀请码签名/校验 | 测试值 | 必填（开启时） |
| `RATE_LIMIT_*` | 登录/注册限流 | 宽松值 | 按压测结果 |

> 密钥只放 `.env` / 平台密钥管理，不提交仓库、不回显、不写日志。仓库只保留 `.env.example` 的变量名与说明。
