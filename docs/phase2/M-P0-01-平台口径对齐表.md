旧 code 只做**读取兼容**：历史内容、历史账号、历史指标仍能显示中文名；新建内容、默认筛选、默认账号绑定不再产生 `shipinhao / moments`。

## 4. 前端落地规则

1. `web/js/core/status.js` 维护 `PLATFORM_META`，字段：`code / name / category / enabled / template / hasVariant / home / sort`。
2. `web/js/core/format.js` 的 `PLATFORMS` 只导出默认四平台；`LEGACY_PLATFORMS` 单独导出迁移期 code。
3. 平台中文名统一走 `platformName(code)`；未知 code 回退显示原始 code，不显示空白。
4. 平台筛选、账号筛选、内容版本标签都从 `PLATFORM_META` 生成选项，不手写第二份数组。
5. 闲鱼只出现在工作台通道与账号配置中；内容管理不生成闲鱼版本，筛选闲鱼时显示空态说明。

## 5. 验收清单

- [ ] 默认四平台在代码中只有一处定义（`PLATFORM_META`），其他模块引用它。
- [ ] 新建内容/生成任务不再产生 `shipinhao / moments`。
- [ ] 历史 `shipinhao / moments` 内容仍能正确显示中文名。
- [ ] `xianyu` 不再触发 422；工作台可复制闲鱼格式文案。
- [ ] 平台筛选、账号配置、评论任务、私信任务的下拉选项均为同一组默认四平台 + 已启用的自定义模板。
- [ ] 验收文档中不再出现「公众号/抖音/视频号/朋友圈」作为默认四平台的表述。
