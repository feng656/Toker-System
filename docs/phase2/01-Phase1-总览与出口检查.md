## 2. 本批实际交付

### 2.1 页面与交互

- **R4 内容管理**
  - 多维筛选：平台、内容状态、版本状态、业务线、关键词、排期起止、最低质量分、合规、确认状态、仅待办；条件写入 URL，刷新不丢。
  - 批量审批：全选/半选、整批预检、失败原因逐项展示；批量端点 404/405 时自动逐条兼容，并明确提示“可能部分写入”。
  - 版本对比：同一内容/平台 revision 链，标题/话题字符级 diff、正文行级并排 diff；纯前端计算，正文不出本机。
  - 待办联动：今日/明日累计/待人工确认/已拦截/平均质量分；与列表同源。
  - 线索转选题：预填业务线/主题/标题/角度；来源标记“来源线索 #id｜平台｜访客”、原始需求与建议话术写入角度；重复线索默认阻止，勾选后才可再建。
  - 线索详情：通过 `GET /interactions` 按 `interaction_id` 展示评论/私信原文；无 `permalink` 时明确提示不能回链原帖。
- **R8 导航**
  - 6 个一级菜单：工作台 / 内容 / 素材 / 线索 / 数据 / 设置；9 个页面路由。
  - 旧入口 `#/todo`、`#/topics`、`#/help` 自动重定向；未知路由显示“页面不存在”。
  - sales 仅见线索/数据/设置；直接访问 `#/contents` 被角色守卫拦截；销售不显示评论录入、推送企微、转选题等无权限按钮。
- **R10 登录/注册**
  - 注册默认关闭提示；开启时邀请码必填、密码强度、两次一致、待审批状态说明。
  - 401 统一“账号或密码错误”，不区分账号是否存在；429 显示安全验证、倒计时、禁用登录。
  - 注意：429 交互是**前端桩验证**，不代表后端已限流。

## 4. 已知限制（不影响演示，但影响生产验收）

1. **数据规模**：演示库 SQLite、内容量小；筛选与统计在前端完成，真实数据量下需后端过滤与分页。
2. **批量兼容模式非原子**：逐条写入中途失败不回滚，界面已提示核对列表；后端批量接口上线后应删除该分支。
3. **选题来源是文本**：`topics` 无来源字段，来源写入 `angle`，不能做外键统计；评论无 `permalink`，不能一键打开原帖。
4. **429 证据是桩**：只证明前端能处理 429，不证明后端会返回 429。
5. **演示数据只在本地**：验收用的线索 #1、选题 #3、销售账号 `qa_sales` 等均未提交仓库，换环境需重新造数。
6. **未做真实平台发布**：R4/R8/R10 的验收均不涉及抖音/小红书/公众号/闲鱼真实接口；平台能力属于后续模块。
