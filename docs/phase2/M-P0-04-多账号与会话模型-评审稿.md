# M-P0-04 多账号与会话模型（评审稿）

> 版本：v0.1-评审稿　日期：2026-11-09　状态：待浆果评审签字
> 依据：D-01 默认四平台、D-03 关键节点人工确认；`app/models.py` 现有 `PlatformAccount`
> 目标：同一平台支持多个账号；账号登录态可加密保存、失效、重新扫码；沙盒/评论/私信任务必须带 `account_id`。

## 1. 现状与问题

| 现状 | 问题 |
|---|---|
| `platform_accounts.platform` 有 `UNIQUE` | 一个平台只能存一个账号，无法同时运营多个抖音号/公众号 |
| 只有 `appid/appsecret/access_token` | 适合官方 API，不适合网页版会话；没有扫码登录态 |
| 没有 `account_id` 贯穿任务 | 沙盒、评论、私信只能按平台找账号，多账号时无法隔离 |
| 没有会话过期/失效模型 | 登录态过期只能报错，不能提示重新扫码 |
| 没有账号状态机 | 无法区分「未绑定 / 待扫码 / 已登录 / 已过期 / 已停用」 |

## 2. 账号表 `platform_accounts`（改造）

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `id` | 整数主键 | 是 | 自增 | 稳定主键 |
| `platform_id` | 外键 `platforms.id` | 是 | - | 关联平台字典 |
| `account_key` | varchar(64) | 是 | `default` | 同一平台内唯一；建议用平台账号 ID 的哈希，不存明文 |
| `display_name` | varchar(100) | 是 | `''` | 运营可读名称，如「自由光抖音一号」 |
| `login_type` | varchar(20) | 是 | `official` | `official / browser_session / qr_code` |
| `status` | varchar(20) | 是 | `unbound` | `unbound / qr_pending / logged_in / expired / disabled` |
| `is_default` | 布尔 | 是 | `false` | 同一平台最多一个默认账号 |
| `appid` | varchar(100) | 否 | `''` | 官方 API 用 |
| `appsecret` | varchar(200) | 否 | `''` | **加密存储，接口只写不读** |
| `access_token` | varchar(500) | 否 | `''` | **加密存储，接口只写不读** |
| `token_expires_at` | datetime | 否 | null | 官方 token 过期时间 |
| `extra` | JSON | 否 | `{}` | 平台特殊配置；不得放密钥明文 |
| `enabled` | 布尔 | 是 | `true` | 停用后不参与新任务 |
| 公共字段 | - | 是 | - | `created_at / updated_at / deleted_at / version` |

约束：

- `UNIQUE(platform_id, account_key)`（逻辑删除后仍唯一）。
- `INDEX(platform_id, status, enabled)`。
- 部分唯一索引：同一 `platform_id` 下 `is_default=true AND deleted_at IS NULL` 只能一条。

迁移：旧记录 `account_key='default'`、`status='logged_in'`（若 `enabled=true` 且有 token）、`is_default=true`；保留旧 `platform` 字符串列一个迭代用于回滚。

## 3. 会话表 `platform_sessions`

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | 整数主键 | 是 | - |
| `account_id` | 外键 `platform_accounts.id` | 是 | 一个账号可有多次会话，只有最新有效 |
| `status` | varchar(20) | 是 | `active / expired / revoked` |
| `storage_state_enc` | text | 是 | 浏览器 storage_state / cookie 的加密信封；**绝不返回前端** |
| `enc_key_id` | varchar(50) | 是 | 密钥版本，便于轮换 |
| `expires_at` | datetime | 否 | 过期时间；网页会话可空 |
| `last_verified_at` | datetime | 否 | 最近一次校验登录态 |
| `last_error` | varchar(300) | 否 | 最近失败原因（脱敏） |
| 公共字段 | - | 是 | - |

规则：

- 只允许一个 `active` 会话 per account；新建时把旧会话置 `revoked`。
- `storage_state_enc` 用 AES-GCM 或平台 KMS 信封加密；密钥不落库、不进日志、不进 Git。
- `GET /accounts` 永不返回 `storage_state_enc / appsecret / access_token`；只返回 `has_session / expires_at / status`。
- 会话失效：`status=expired`，账号 `status=expired`；任务创建时校验，失败返回 409/422 并提示重新扫码。
- 账号隔离：同一账号同时只允许一个浏览器会话任务；跨账号可并行，但受全局并发上限限制。

## 4. 状态机

### 4.1 账号状态

```text
unbound --绑定--> qr_pending --扫码成功--> logged_in --过期--> expired --重新扫码--> qr_pending
   |                  |                       |                    |
   +------停用--------+------停用-------------+--------停用--------> disabled
```

| 状态 | 中文文案 | 可执行下一步 |
|---|---|---|
| `unbound` | 未绑定 | 绑定账号 / 扫码登录 |
| `qr_pending` | 等待扫码 | 打开二维码 / 取消 |
| `logged_in` | 已登录 | 打开后台 / 重新扫码 / 停用 |
| `expired` | 登录已过期 | 重新扫码 |
| `disabled` | 已停用 | 启用（管理员） |

### 4.2 会话状态

| 状态 | 文案 | 下一步 |
|---|---|---|
| `active` | 有效 | 可执行任务 |
| `expired` | 已过期 | 重新扫码 |
| `revoked` | 已失效 | 重新登录 |

## 5. 任务表加 `account_id`

| 表 / 模块 | 变更 | 规则 |
|---|---|---|
| `sandbox_tasks`（R2 新增） | `account_id` 必填 | 打开平台、搜索、发布都按账号隔离 |
| `comment_tasks`（R7 新增） | `account_id` 必填 | 评论账号与内容平台一致；跨平台任务 422 |
| `dm_tasks`（R11 新增） | `account_id` 必填 | 私信必须指定账号；默认账号仅作 UI 预选 |
| `ocr_tasks` | `account_id` 可空 | 截图识别不强制账号；有账号时用于归属 |
| `metrics` | 不加 | 指标按 variant 归属，账号仅用于采集来源 |
| `interactions` | 可加 `account_id` 可空 | 评论/私信来源账号，便于回溯 |

创建任务时统一校验：

1. `account_id` 存在、未删除、`enabled=true`、`status=logged_in`；
2. 账号所属 `platform_id` 与任务平台一致；
3. 账号会话 `active` 且未过期；
4. 同一账号同时运行的任务数不超过 `config.max_parallel`（默认 1）。

失败返回：

- `404 account_not_found`：账号不存在或无权；
- `409 account_not_ready`：`detail` 带 `status / next_action`；
- `422 platform_mismatch`：账号平台与任务平台不一致。

## 6. 接口草案

| 方法 | 路径 | 用途 |
|---|---|---|
| `GET` | `/platforms/{pid}/accounts` | 账号列表；不含密钥/会话 |
| `POST` | `/platforms/{pid}/accounts` | 新增账号（官方 API 凭据或扫码初始化） |
| `PUT` | `/accounts/{aid}` | 改显示名、默认账号、启用状态 |
| `DELETE` | `/accounts/{aid}` | 软删除；有运行中任务返回 409 |
| `POST` | `/accounts/{aid}/qr` | 发起扫码；返回二维码（base64/URL）与过期时间 |
| `GET` | `/accounts/{aid}/qr/status` | 轮询扫码状态：`qr_pending / logged_in / expired` |
| `POST` | `/accounts/{aid}/session/verify` | 校验登录态 |
| `POST` | `/accounts/{aid}/session/revoke` | 主动失效会话 |

二维码/轮询不返回 cookie、token、storage_state；只返回状态与脱敏账号名。

## 7. 安全与审计

- 密钥字段加密存储；日志脱敏（只显示后四位或 `***`）。
- 所有账号操作写审计：`actor / action / account_id / ip / ua / result`。
- 扫码登录不承诺绕过平台风控；失败时提示「平台要求人工验证，请打开窗口处理」。
- 账号停用/删除前检查运行中任务与未完成出站消息；有则阻止并提示。
- 会话加密密钥轮换时保留 `enc_key_id`，旧会话可解密或强制重新扫码。
