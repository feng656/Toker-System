# 平台账号模块视觉交付说明

## 范围与结论

按用户截图对现有Vue/Element Plus工作台做局部增量，不改整站风格、不换框架。账号列表、添加平台/账号及扫码弹窗由独立组件负责；新增CSS使用现有Element Plus变量，保留深色顶栏、左侧菜单和白色卡片。

## 设计检查实际状态

- 仓库未绑定平台设计系统，无设计系统kit或金样。没有为本次小范围需求擅自引入新设计系统或整体scaffold。
- 自动verify前后均识别未绑定（25分、1/7必过项；工具把此原生脚本项目判A态，并不代表仓库是空白项目）。**未通过平台设计系统认证，不宣称金样一致性通过。**
- `design check`因未指定/绑定设计系统拒绝执行；不绕过成绿、不把拒绝说成通过。此任务使用现有组件库及CSS变量，局部无新硬编码色。
- 真实受管浏览器完成桌面1440×1000及手机390×844视口验证；添加弹窗内可滚动，底部操作保持可见，账号弹窗横向无溢出。
- 手动核图：搜索与选中态清晰；停用态及启用位置可见；自定义平台保存后可再次选择；未接入时无空转“生成中”或假二维码；扫码成功状态只作明确标注的测试替身验证。

## 截图与边界

交付截图仅呈现真实渲染的目录/保存/缺依赖提示，不把模拟扫码成功截图作为业务成果。所有账号和自定义平台均为独立测试schema中的虚构数据。旧工作台其他页面、未知浏览器与真实移动设备未做全面验收。
