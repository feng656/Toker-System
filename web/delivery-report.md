## 五、工程价值

1. **可维护**：页面 → 服务层 → HTTP 层三层分离，后端契约变更的影响面从「整页」缩小到「一行服务调用」。
2. **不臆造能力**：16 条后端缺口逐条登记并在页面上标注编号，运营看到的是「暂不可用 + 原因 + 找谁」，而不是假数据或空白。
3. **硬门槛落到代码**：空链接不计入发布量、红线不放行，两条都在前端有强制校验并有自动化断言。
4. **离线可跑**：依赖本地自托管，不依赖 CDN；后端一启动即可用。
5. **口径单一来源**：状态中文文案只存在于 `js/core/format.js`，与《业务规则与状态口径说明》一一对应，避免前后端各说一套。
